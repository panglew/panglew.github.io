EECS 491: P4 - Sharded Key-Value Service w/ Paxos Groups

Languages & Tools Used: Go

  • Designed and implemented a fault-tolerant, sharded key/value storage system in Go, ensuring linearizable consistency across distributed replica groups
  • Integrated Paxos-based consensus within each replica group to replicate data and handle dynamic reconfiguration reliably
  • Developed a centralized Shard Master service (also Paxos-backed) to manage shard-to-group assignments via configurable Join, Leave, Move, and Query RPCs
  • Engineered a reconfiguration protocol to transfer shards between replica groups while preserving consistency during concurrent client operations
  • Enabled shard handoffs using custom RPCs (AssignShard, PullShard), coordinating safe data migration and duplicate request handling across configurations
  • Achieved fault tolerance under partial network partitions and server failures, ensuring availability and correctness of Get, Put, and Append operations
